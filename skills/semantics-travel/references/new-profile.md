# Новий профіль ринку (країна/мова)

Профіль - `scripts/profiles/<код>.json` (код = TLD `se_domain`, напр. `at`, або мова, або `profile:` у CLAUDE.md). Німецькомовні ринки (de/at/ch) використовують `de.json`.

1. Збери ТОП-10 (`fetch_serp.py`) для 20-30 ключів і подивись URL/заголовки конкурентів: як називаються хаб напрямку, last minute, пакетний тур, all inclusive, готелі, інформаційні сторінки.
2. Скопіюй `de.json` у `<код>.json` і заміни:
   - `modifiers` (ціна, місяці) і `lemma_rules` (регулярні вирази лем, порядок важливий; плейсхолдери `{price}`, `{months}`), `cluster_names`;
   - `landing`: `path_rules`, `title_rules` (плейсхолдер `{country_lc}`), `info_domains`, `tour_domains`, `hub_roots`;
   - `page_slugs` (як називаються сторінки на САЙТІ клієнта), `topic`, `keyword_family`;
   - `tokens` (стоп-слова, множина, загальні й інформаційні токени, `region_seed_word`), `stop_brands`, `notes`;
   - `destinations`: регіони/курорти країн призначення (`slug країни → regions → назва: regex`), якщо їх не задано рядками `region:` у CLAUDE.md.
3. Запусти `analyze.py` і перевір аркуш «Типи посадкових конкурентів»: «інше» має бути невеликою часткою; допиши правила для частих «інше».
4. Для одного проєкту достатньо `semantics-profile.json` у робочій папці: словники зливаються з профілем, списки й значення замінюються.

## Розділи `scope` і `seed_templates` (межі теми й seed)
- `scope.products`: продукти, які для сторінки «країна + відпочинок/тур» є **суміжними** (гарячі тури, готелі, авіаквитки, екскурсійні тури, круїзи, оренда житла/авто...): `match` (regex мови ринку), `exclude` (необов'язково), `name` (укр. назва теми), `sells` (чи продає сайт; впливає на рекомендацію).
- `scope.junk`: група → regex сміття (погода, віза, новини/безпека, карти/довідка, не туризм, форум).
- `seed_templates`: `{t}` - тема (країна/напрямок мовою ринку); групи `main`, `product_synonyms`, `word_order`, `adjacent_optional`. Для ринку з двома мовами семантики (напр. Україна: uk + ru) потрібен профіль на кожну мову і `semantic_languages: uk|ru` у CLAUDE.md.
- Райони/регіони для впізнавання беруться з `destinations.<країна>.regions` або `region:` у CLAUDE.md.
